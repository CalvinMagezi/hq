**Connected assistants find tools with fewer tokens.** Asking HQ's tool search for something now returns the best few matches first, each with a one-line call shape instead of a full schema, so a harness or connected assistant spends a fraction of the tokens to find the right tool. A search in plain words, such as "search my vault", now works where it used to need an exact phrase. Ask for one tool by its exact name, or pass `detail`, to get the full parameters.

**Slides, comments and live updates on the phone.** A slides note now opens as a list of 16:9 cards. Tap one to edit its title, text, speaker notes, layout and transition, move it up or down, delete it, or add a card. Notes made by the HQ Suite have a Comments page: open comments first, a Resolve button, and an Add button that asks which block the comment is about. "Edit by block" can now insert a table and find and replace across the note. An open note reloads by itself when the web app or an agent changes it, and waits until a dialog you have open is closed.

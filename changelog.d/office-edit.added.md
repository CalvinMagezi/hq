**HQ can change a sheet, document or deck you already have.** Ask in chat to fix a paragraph, add a card, or change a cell and HQ edits that one part (`office_edit`) instead of making a second copy. If the note changed since HQ read it, the edit is refused and nothing is written. The text HQ replaced is kept, so the note's Undo works, and a note HQ makes or edits is marked as HQ's.

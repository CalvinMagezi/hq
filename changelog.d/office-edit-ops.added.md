**HQ can now reshape a sheet, a deck and a dashboard, not just one cell or block.** In chat, HQ can fill a range of cells, add or delete rows, add a column or set its type, add a sheet, add, replace, move and delete a deck's cards, set speaker notes and a card's transition, colours and layout, and add a tile or a chart built from a sheet range (it draws it first, and says why if it would not draw). Anything that deletes, or touches more than 50 cells, is shown as a preview first and applied only on a second call, and only if the note has not changed since. Rows are not inserted or deleted where a formula, tile or chart reads the rows below; HQ says which one. Open pages reload a note the moment it changes.

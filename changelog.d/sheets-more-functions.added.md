**Sheets calculate many more functions.** The sheet engine now reads `SUMIFS`, `COUNTIFS`, `AVERAGEIF(S)`, `MAXIFS`, `MINIFS`, `MEDIAN`, `LARGE`, `SMALL`, `RANK`, `MATCH`, `LOOKUP`, `HLOOKUP`, `IFNA`, `VALUE`, `MID`, `REPT`, `PROPER`, `EXACT`, `TRUNC`, `CEILING`, `FLOOR`, `DATE`, `YEAR`, `MONTH`, `DAY`, `WEEKDAY`, `EOMONTH` and `DATEDIF`, whole-column ranges such as `$B:$B`, and `TEXT` with date formats (`yyyy-mm-dd`, `dd/mm/yyyy`, `mmm yyyy`) and currency-like formats. `ROUND` now agrees with Excel on cases like `ROUND(1.005,2)`, and `COUNTIF(range,0)` no longer counts blank cells. Anything that cannot be reproduced exactly (`TODAY`, `SUMPRODUCT`, `FILTER`, table references, an unsorted approximate `MATCH`, time formats) is still shown as "cannot calculate" instead of a guessed number.

**Review comments in docs, slides, sheets and dashboards.** A Comments button, with a count of open comments, opens a sheet that lists them (open first, resolved in a collapsed list), says who wrote each, when, and which block it is about, and marks one whose block has since changed. You can resolve a comment and add one: it starts on the block you selected in a doc, the card you are on in slides, or the sheet you are looking at, and a picker lists every other block. Comments need HQ, so they wait while it cannot be reached. In the note itself a comment is no longer drawn as a code block: a small "2 comments" marker stands after the block it is about.

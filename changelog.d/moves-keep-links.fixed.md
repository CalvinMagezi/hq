**Moving or renaming a note no longer breaks links to it.** Links with a heading (`[[Plan#Goals]]`), a folder (`[[Projects/Plan]]`), a `.md` ending, an embed or a markdown link now follow the note, and so do the links inside a note that moves to another folder. Moving a whole folder fixes links into it as well. A link that could mean either of two notes with the same name is left alone and listed in the move report instead of being pointed at the wrong one. Before, only plain `[[Name]]` links were rewritten, and every note with the old name was rewritten along with it.

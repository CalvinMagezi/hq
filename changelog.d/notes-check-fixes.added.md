**HQ can fix the broken links it is sure about, and every fix can be undone.** `hq vault health --apply` fixes links whose folder is out of date, links to a note that was renamed, and notes with a second block of properties; `--tier all` also fixes a misspelt link when one note is clearly meant, settles a name that fits several notes by the folder it is in, and removes a note that repeats another word for word, pointing its links at the one that stays. Each run first saves the original of every note it changes, and `hq vault repair --undo <run>` puts them back, leaving any note you edited since. HQ never changes sheets, decks, pinned notes, notes an assistant wrote that you have not reviewed, or a note changed in the last ten minutes. Turn on `daemon.vault_auto_fix` to let HQ do the certain fixes after each check; it stops by itself if you keep undoing them. HQ also lists notes that say almost the same thing, using only the model that runs on your device.

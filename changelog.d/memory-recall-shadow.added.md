**HQ can now bring up the memories that fit what you just said, and shows you how well it would do before you switch it on.** Until now every chat got the same handful of "most important" memories whatever you asked. A new setting, `daemon.memory_recall`, chooses how memory reaches a chat. The default, `shadow`, changes nothing you see: chats still work as before, and in the background HQ works out which memories would have fit each message and writes down only counts, ids and timings (never your words). Run `hq memory recall-report` to see how often it found something, how fast it was, and whether it is ready. When you are happy, set `daemon.memory_recall: query` and each message brings up only the memories that fit it, and nothing when none do. `recent` keeps the old behaviour with no lookup, and `off` stops memories learned from chats from being brought up at all (`MEMORY.md` still is). Only your own chats get this: a guest never does.

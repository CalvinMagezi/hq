# No capture on the phone

Import is `hq finance import <file>` on a computer. There is no share target or file picker in the Android app, so a person with only a phone cannot use the ledger yet. Notification and SMS access are deliberately not built (see the plan note in the vault).

Fix when: the data-flow review in `docs/finance/README.md` is accepted. Start with a file picker that runs the same import on the device.

File: `apps/android/`.
